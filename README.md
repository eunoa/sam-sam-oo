## Git 협업 규칙

- main 브랜치에 직접 push하지 않습니다.
- 기능별 브랜치를 생성하여 작업합니다.
- 작업 완료 후 Pull Request를 생성합니다.
- Pull Request 확인 후 main에 merge합니다.
- commit 메시지는 작업 내용을 알 수 있도록 작성합니다.
